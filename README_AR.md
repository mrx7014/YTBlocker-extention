# حاجب قنوات YouTube

إضافة متصفح خفيفة لإخفاء الفيديوهات والتعليقات ونتائج البحث وبطاقات القنوات وقوائم التشغيل وغيرها من محتوى YouTube الصادر عن القنوات التي تختار حظرها.

تستخدم الإضافة Manifest V3 وتحفظ قائمة الحظر عبر `chrome.storage.sync` لمزامنتها مع ملف المتصفح الشخصي في المتصفحات المدعومة.

## المعاينة

تتيح النافذة المنبثقة إضافة القنوات بسرعة، ومعاينة القناة في الصفحة الحالية، وتفعيل الفلترة أو تعطيلها، وإزالة العناصر من القائمة.

![معاينة النافذة المنبثقة](assets/screenshots/popup-preview.png)

توفر صفحة الإعدادات إدارة كاملة لقائمة الحظر، وأنواع المطابقة، والاستيراد والتصدير، وخيارات التصفية.

![معاينة صفحة الإعدادات](assets/screenshots/options-preview.png)

## الميزات

- حظر القنوات باستخدام معرّف القناة أو `@handle` أو الاسم الظاهر.
- إخفاء المحتوى المحظور من الخلاصات ونتائج البحث وصفحات المشاهدة والقنوات وقوائم التشغيل وواجهات Shorts والتعليقات.
- استبدال صفحة القناة المحظورة، بما يشمل تبويبات الفيديوهات وShorts والبث والمجتمع، بتنبيه واضح وإجراء لإلغاء الحظر.
- إخفاء بطاقات الفيديو والمنشورات التي تشير روابطها إلى قناة محظورة، بما فيها بعض بطاقات التعاون حين تظهر هوية القناة.
- إيقاف مشغل صفحة المشاهدة المحظورة وكتمه، مع إتاحة إجراء لإلغاء الحظر ومشاهدة المحتوى واستعادة حالة الصوت السابقة.
- حظر القنوات من النافذة المنبثقة أو قائمة النقر بزر الفأرة الأيمن أو زر الإضافة على البطاقات المدعومة.
- إضافة القنوات يدويًا عبر الرابط أو المعرّف أو الاسم أو `@handle`.
- إدارة القائمة والبحث فيها وفرزها وحذف عناصر منها واستيرادها وتصديرها من صفحة الإعدادات.
- استيراد وتصدير JSON وCSV، وإضافة تصنيفات وملاحظات للقنوات.
- اختيار مدة الحظر: ساعة أو 24 ساعة أو 7 أيام، أو إبقاؤه حتى إلغاء الحظر يدويًا.
- إنشاء استثناءات بقائمة السماح، وتحديد قنوات متعددة وتصديرها أو إزالتها دفعة واحدة.
- التراجع عن بعض عمليات الحظر أو إلغاء الحظر الأخيرة.
- اختيار إخفاء البطاقات المحظورة أو استبدالها بتنبيه، وتفعيل أو تعطيل التصفية عمومًا دون حذف القائمة.
- إضافة قواعد لتصفية الفيديوهات بحسب كلمات أو عبارات العنوان، بمطابقة العبارة أو الكلمة كاملة.
- إظهار عدّاد محلي تقريبي للعناصر التي تمت فلترتها وإمكانية تصفيره.
- دعم متصفحات Chromium المتوافقة مع Manifest V3، وحزمة منفصلة لـ Firefox على Android.

## الجديد في 2.0.0

يجمع الإصدار الرئيسي 2.0.0 الميزات التي أُضيفت بعد 1.1.0: حظر صفحات القنوات والبطاقات المرتبطة بها، معالجة الصوت في صفحات المشاهدة المحظورة، تحسين إدارة القائمة، استيراد وتصدير JSON وCSV، الحظر المؤقت والاستثناءات والتصنيفات والملاحظات والتراجع والإحصاءات التقريبية، ثم فلترة عناوين الفيديوهات بالكلمات. كما تتضمن هذه النسخة حزمًا مستقلة لسطح المكتب وأندرويد وسير عمل آليًا للتحقق والبناء. التفاصيل الكاملة في [سجل التغييرات](CHANGELOG_AR.md) أو [السجل الإنجليزي](CHANGELOG.md).

## التثبيت والتحديث

### متصفحات Chromium على سطح المكتب

1. نزّل حزمة سطح المكتب `youtube-channel-blocker-desktop-v2.0.0.zip` من مخرجات تشغيل GitHub Actions المكتمل، ثم فك ضغطها إلى مجلد ثابت.
2. افتح صفحة الإضافات في متصفحك: `chrome://extensions` في Chrome أو `edge://extensions` في Edge أو `brave://extensions` في Brave.
3. فعّل **وضع المطوّر**.
4. اختر **تحميل إضافة غير معبأة (Load unpacked)** وحدد المجلد الذي يحتوي `manifest.json`.
5. عند التحديث، فك ضغط النسخة الجديدة إلى المجلد الثابت نفسه، ثم اختر **إعادة التحميل (Reload)** للإضافة من صفحة الإضافات. لا تحمّل نسختين من المجلد نفسه ولا تحذف بيانات المتصفح؛ تحتفظ الإضافة بقائمة الحظر في تخزين المتصفح.

### Firefox على Android

نزّل حزمة Android المخصصة لـ Firefox من مخرجات البناء. تتطلب هذه الحزمة Firefox for Android 142 أو أحدث. قد تتطلب عملية التثبيت خارج قناة Mozilla Add-ons تحميلًا مؤقتًا أو إعدادات خاصة بإصدار Firefox. الإضافة المنشورة دائمًا تحتاج إلى توقيع من Mozilla Add-ons.

### التطوير المحلي

1. استنسخ هذا المستودع أو نزّله.
2. افتح صفحة الإضافات المناسبة لمتصفحك.
3. فعّل وضع المطوّر ثم اختر **Load unpacked** وحدد جذر المستودع، أي المجلد الذي يحتوي `manifest.json`.
4. بعد تعديل الملفات، ارجع إلى صفحة الإضافات واختر **Reload**.

لدعم Firefox المؤقت على سطح المكتب، افتح `about:debugging` واختر **Load Temporary Add-on**. التثبيت الدائم يتطلب توقيع الإضافة من Mozilla.

## الاستخدام

### حظر قناة من YouTube

انقر بزر الفأرة الأيمن على رابط القناة واختر **Block this YouTube channel**. تعرض الإضافة تأكيدًا قبل حفظ القناة. كما يمكنك استخدام زر الحظر على بطاقة مدعومة، أو فتح النافذة المنبثقة واختيار حظر القناة المكتشفة في صفحة YouTube الحالية.

### إضافة قناة يدويًا

تقبل النافذة المنبثقة وصفحة الإعدادات أحد الأنواع التالية:

| الإدخال | مثال | سلوك المطابقة |
| --- | --- | --- |
| معرّف القناة | `UCxxxxxxxxxxxxxxxxxxxxxx` | مطابقة دقيقة لمعرّف القناة |
| المعرّف المختصر | `@example` | مطابقة دقيقة للـhandle |
| رابط القناة | `https://www.youtube.com/@example` | استخراج الـhandle أو معرّف القناة |
| الاسم الظاهر | `Example Channel` | مطابقة غير حساسة لحالة الأحرف وقد تكون تقريبية |

قد تطابق الأسماء قنوات متعددة متشابهة؛ استخدم معرّف القناة أو `@handle` عندما تكون الدقة مهمة.

## البناء محليًا

لا تحتاج الإضافة إلى تثبيت اعتماديات أو استخدام أداة تجميع. للتحقق من الملفات وبناء الحزمتين على Linux أو macOS:

```bash
python3 -m json.tool manifest.json >/dev/null
python3 -m json.tool platforms/web/manifest.json >/dev/null
python3 -m json.tool platforms/android/manifest.json >/dev/null
for file in *.js; do node --check "$file"; done
bash build-extensions.sh
```

ينشئ البناء حزمًا مرقّمة في `dist/` لسطح المكتب وAndroid. حمّل إصدار المنصة المناسبة من قسم **Artifacts** في تشغيل GitHub Actions المكتمل. للاستخدام أثناء التطوير، حمّل مجلد المصدر مباشرة بدل ملف ZIP.

## الخصوصية والأذونات

لا ترسل الإضافة قائمة الحظر إلى خادم تابع لجهة خارجية. تستخدم تخزين الإضافة المتزامن في المتصفح، وتعمل على صفحات YouTube التي تغطيها المطابقات وأذونات المضيف فقط.

| الإذن | الغرض |
| --- | --- |
| `storage` | حفظ القائمة وحالة التفعيل والإعدادات |
| `contextMenus` | إضافة إجراءات حظر القناة إلى قائمة النقر الأيمن |
| `activeTab` | فحص علامة التبويب النشطة من النافذة المنبثقة |
| `scripting` | اكتشاف القناة الحالية في علامة التبويب النشطة |
| الوصول إلى YouTube | فحص صفحات YouTube وتصفيتها |

## حدود معروفة

قد تغيّر YouTube بنية الصفحات، ما قد يتطلب تحديث محددات DOM في `content.js`. تعتمد فلترة التعاون على وجود رابط أو هوية ظاهرة للقناة في البطاقة؛ لذلك لا يمكن اكتشاف كل الحالات. المطابقة بالاسم الظاهر أقل دقة من المعرّف أو الـhandle.

تعمل الإضافة كفلتر من جهة العميل: فهي لا تمنع تنزيل المحتوى ولا تحظر المواقع خارج YouTube، ولا تضمن اكتشاف كل أنواع المحتوى. في صفحة القناة نفسها تغطي المحتوى بتنبيه، وفي الصفحات الأخرى تخفي البطاقات المدعومة المطابقة.

## المساهمة

نرحب بالإبلاغ عن الأخطاء واقتراح التحسينات. عند الإبلاغ عن مشكلة في الفلترة، اذكر نوع صفحة YouTube والمتصفح وإصداره ورابط القناة المعنية إن أمكن. لا ترسل معلومات حساب خاصة أو بيانات اعتماد.
